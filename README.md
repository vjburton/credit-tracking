# InsectAI COST Action CRediT Contributor Register

This repository contains a structured Excel workbook used to track contributions to the InsectAI COST Action using the CRediT typology (https://credit.niso.org). It provides a single-row-per-person layout with role selection via dropdown boxes.

## Purpose

The spreadsheet enables us to:

- Record participant names and associated roles
- Capture multiple roles per person in a consistent, controlled format
- Maintain a transparent, version-controlled history of credit changes through GitHub

## How to Use the Spreadsheet

### Adding a New Individual

1. Insert a new row in the main table.
2. Enter the participant’s title, name, institution, and ORCID (if applicable).
3. Select relevant roles within the COST Action using the dropdown boxes (see the CRediT Definitions sheet for explanations of each role).
4. Add any additional information in the Contribution Details column.

### Updating an Individual

1. Locate the individual in the table.
2. Update personal details as needed.
3. Add or remove roles using the dropdown boxes.
4. Update contribution details if required.

## Version Control Guidance

Because Excel files are binary, please follow these practices to minimise merge conflicts:

- Make changes in small, clear commits.
- Avoid editing the same rows as someone else simultaneously.
- Use descriptive commit messages (e.g., "Added roles for Dr A. Smith").
